# Báo cáo LaTeX

Thư mục này dùng mẫu llncs của Springer Computer Science Proceedings.

## File chính

- main.tex: nội dung báo cáo.
- figures/system-pipeline.png: hình pipeline chính dùng trong báo cáo.
- llncs.cls: class trình bày theo mẫu LNCS. Báo cáo nội bộ hiện không dùng trích
  dẫn hoặc danh mục tài liệu tham khảo.

## Biên dịch

Trên Overleaf, tải toàn bộ thư mục report lên và đặt main.tex làm Main
Document. Chọn trình biên dịch XeLaTeX để hiển thị đầy đủ tiếng Việt, sau đó
biên dịch bằng:

    xelatex main.tex
